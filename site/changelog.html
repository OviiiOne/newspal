What changed in each version · Qué cambia en cada versión

2.4.0

2026

English

  • Reloading a page no longer kills the session. The panel comes back on its own with the transcript, the key points and the summary it already had.
  • Closing asks first. The ✕ now offers to export the session — with or without generating the summary first — before discarding it.
  • Name a speaker from a key point. Click the speaker tag on any card to put a name to it; the name is added to the participants so the rest of the session is attributed to them.
  • All 99 Gladia languages. The press-conference language is chosen from a search box: type the name, in either language, or the code.
  • Automatic detection actually detects. Auto mode no longer sends a language shortlist the API does not support.
  • Unsigned builds are marked. Versions loaded from disk show a β next to the version number.

Español

  • Recargar la página ya no mata la sesión. El panel vuelve solo con la transcripción, los puntos clave y el resumen que ya tenía.
  • Cerrar pregunta antes. La ✕ ofrece exportar la sesión —con o sin generar el resumen— antes de descartarla.
  • Poner nombre al hablante desde un punto clave. Pincha en la etiqueta de la tarjeta para nombrarlo; el nombre se añade a participantes y el resto de la sesión se le atribuye.
  • Los 99 idiomas de Gladia. El idioma de la rueda de prensa se elige desde un buscador: escribe el nombre, en cualquiera de los dos idiomas, o el código.
  • La detección automática detecta de verdad. El modo automático ya no manda una lista de idiomas que la API no admite.
  • Las versiones sin firmar se distinguen. Las cargadas desde el disco muestran una β junto al número de versión.

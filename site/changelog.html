What changed in each version · Qué cambia en cada versión

2.4.0

2026-09-26

English

  • Live translation with Gladia. Each line is translated as it arrives; if Gladia doesn't translate it, Google steps in, and AI as a last resort. AI translations are labelled as such.
  • No half-translations. A translation that leaves parts untranslated is discarded and another route is used.
  • One key point per statement. No more repeats: a fuller version replaces the earlier one. In interpreted passages, the key point carries the original speaker's timestamp.
  • More faithful summaries. Built from the key points and the transcript, only from what was said, and the AI knows the date and time of the event.
  • Silent-audio warning. If the capture is only silence, the panel says so.
  • Settings inside the popup. Open them with ⚙, go back with ←. The proxy is checked automatically: if it doesn't answer, you can't start.
  • Test models. A button in Settings checks that each AI model in the queue answers.
  • Sturdier Gladia connection. On failure it retries instead of stopping. Messages state the real cause, and Gladia no longer stays blocked by a previous session.
  • Release notes after updating. This page opens after each update (from the next one on).
  • Reloading a page no longer kills the session. The panel comes back on its own with the transcript, the key points and the summary it already had.
  • Closing asks first. The ✕ now offers to export the session — with or without generating the summary first — before discarding it.
  • Name a speaker from a key point. Click the speaker tag on any card to put a name to it; the name is added to the participants so the rest of the session is attributed to them.
  • All 99 Gladia languages. The press-conference language is chosen from a search box: type the name, in either language, or the code.
  • Automatic detection actually detects. Auto mode no longer sends a language shortlist the API does not support.
  • Unsigned builds are marked. Versions loaded from disk show a β next to the version number.

Español

  • Traducción en directo con Gladia. Cada frase se traduce según llega; si Gladia no la traduce, entra Google y, como último recurso, la IA. Las traducciones de la IA van marcadas como tales.
  • Traducciones a medias, fuera. Si una traducción deja trozos sin traducir, se descarta y se usa otra vía.
  • Un punto clave por declaración. Ya no se repiten: si llega una versión más completa, sustituye a la anterior. En pasajes con intérprete, el punto clave lleva la marca de tiempo del orador original.
  • Resúmenes más fieles. Se construyen a partir de los puntos clave y la transcripción, solo con lo que se dijo, y la IA sabe la fecha y la hora del acto.
  • Aviso de audio mudo. Si lo que se captura es solo silencio, el panel lo avisa.
  • Ajustes dentro de la ventanita. Se abren con ⚙ y se vuelve con ←. El proxy se comprueba solo: si no responde, no se puede empezar.
  • Probar modelos. Un botón en Ajustes comprueba que cada modelo de IA de la cola responde.
  • Conexión con Gladia más robusta. Si falla, reintenta en vez de detenerse. Los avisos dicen la causa real, y Gladia ya no se queda bloqueada por una sesión anterior.
  • Notas de versión al actualizar. Tras cada actualización se abre esta página (a partir de la próxima).
  • Recargar la página ya no mata la sesión. El panel vuelve solo con la transcripción, los puntos clave y el resumen que ya tenía.
  • Cerrar pregunta antes. La ✕ ofrece exportar la sesión —con o sin generar el resumen— antes de descartarla.
  • Poner nombre al hablante desde un punto clave. Pincha en la etiqueta de la tarjeta para nombrarlo; el nombre se añade a participantes y el resto de la sesión se le atribuye.
  • Los 99 idiomas de Gladia. El idioma de la rueda de prensa se elige desde un buscador: escribe el nombre, en cualquiera de los dos idiomas, o el código.
  • La detección automática detecta de verdad. El modo automático ya no manda una lista de idiomas que la API no admite.
  • Las versiones sin firmar se distinguen. Las cargadas desde el disco muestran una β junto al número de versión.
